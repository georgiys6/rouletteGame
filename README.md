# 🎡 Backlog Roulette

Рулетка непройденных игр: не знаете, что запустить из бэклога, пусть решит колесо.
Это статический сайт для **GitHub Pages**: без сервера и сборки, данные хранятся у вас.

## Возможности

- **Два режима**
  - **Обычная рулетка**: одна прокрутка, одна игра.
  - **На выбывание**: каждая прокрутка выбивает выпавшую игру, побеждает последняя оставшаяся.
- **Своя гифка в центре колеса**: загрузите файл (хранится в IndexedDB браузера) или дайте ссылку. Можно настроить размер, обрезку по кругу и вращение вместе с колесом. Центр колеса работает как кнопка «Крутить».
- **Гифка прямо с главной страницы**: перетащите файл на колесо или на зону в боковой панели, вставьте картинку из буфера (Ctrl+V) или ссылку. Гифку можно перетащить прямо с giphy или tenor.
- **Скорость вращения**: пресеты «Плавно / Обычно / Быстро / Турбо» и ползунок от 1 до 20 секунд.
- **Без повторов**: одинаковые игры из разных источников и в разном написании (регистр, ™, «Edition», «Remastered», римские цифры, скобки с платформой) склеиваются в одну. Недавно выпавшие игры (последние 1, 3, 5, 10 или вся история) не попадают на колесо.
- **Гифка победы** в окне с результатом.
- 7 палитр колеса, лампочки на ободе, звук щелчков (WebAudio), конфетти, пробел для запуска.
- **Библиотека**: поиск, фильтры, отметки «пройдена» и «исключить», ручное добавление игр.
- Фильтры «непройденности»: для Steam по наигранным часам, для PSN и Xbox по проценту трофеев и достижений.
- Одинаковые игры из разных магазинов объединяются в одну.
- Резервная копия и восстановление (JSON).

## Источники

| Источник | Как попадает | Что нужно |
|---|---|---|
| **Steam** | GitHub Actions или букмарклет | ссылка на профиль в `roulette.config.json` (+ `STEAM_API_KEY` по желанию) или закладка на `steamcommunity.com/my/games/?tab=all` |
| **Backloggd** | букмарклет | закладка на странице Backlog в профиле. Серверный импорт невозможен: сайт блокирует ботов |
| **MyGameList** | букмарклет / CSV | закладка на странице списка или экспорт в CSV |
| **Epic Games** | букмарклет | закладка на `epicgames.com/account/transactions`: читается вся история покупок, включая бесплатные раздачи |
| **PlayStation** | GitHub Actions или букмарклет | секрет `PSN_NPSSO` (трофеи и прогресс) или закладка на `library.playstation.com` |
| **Xbox** | GitHub Actions или букмарклет | секрет `OPENXBL_KEY` (бесплатный ключ на [xbl.io](https://xbl.io)) |
| **Nintendo** | букмарклет / файл | закладка на странице покупок или выделенный список; публичного API нет |
| Любой список | вставка / файл | TXT (игра на строку), CSV, JSON |

### Букмарклет

На вкладке **Импорт** есть кнопка «🎡 В рулетку». Перетащите её на панель закладок.
Затем откройте страницу со своими играми и нажмите закладку. Появится панель со списком найденных игр, его можно поправить. Кнопка «Отправить в рулетку» откроет сайт с данными.
Код выполняется только на открытой вами странице и ничего не отправляет на сторонние серверы.

- Steam: читает встроенный в страницу JSON со всей библиотекой и наигранным временем.
- Backloggd: проходит по всем страницам выбранного списка.
- Epic: запрашивает историю заказов от вашего имени; DLC, валюта и наборы отфильтровываются.
- Остальные сайты: берёт названия с обложек или **выделенный мышкой текст** (по строке на игру).

## Развёртывание на GitHub Pages

1. Создайте репозиторий и загрузите в него эти файлы.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<ник>.github.io/<репозиторий>/`.

### Автосинхронизация (необязательно)

Workflow [`.github/workflows/sync-games.yml`](.github/workflows/sync-games.yml) запускается раз в сутки, вручную (**Actions → Sync game libraries → Run workflow**) и при изменении конфига. Он обновляет `data/games.json`.

1. В `roulette.config.json` укажите профиль Steam (ник из ссылки, SteamID64 или полная ссылка):
   ```json
   { "steam": { "profile": "https://steamcommunity.com/id/your_nick" } }
   ```
2. **Settings → Secrets and variables → Actions → New repository secret**:
   - `STEAM_API_KEY`: ключ с https://steamcommunity.com/dev/apikey. Без ключа скрипт пробует прочитать открытую страницу профиля.
   - `PSN_NPSSO`: войдите на https://www.playstation.com, затем откройте https://ca.account.sony.com/api/v1/ssocookie и скопируйте значение `npsso`. Токен живёт около 2 месяцев.
   - `OPENXBL_KEY`: ключ из личного кабинета https://xbl.io.
3. Для источников без API положите файлы в [`data/import/`](data/import/README.md): `epic.txt`, `nintendo.csv` и т. п.

> ⚠️ `data/games.json` в публичном репозитории виден всем, это ваш список игр. Секреты (ключи и токены) в него не попадают.

Если какой-то источник упал (например, истёк NPSSO), скрипт сохранит его прошлые данные, а сайт покажет ошибку на вкладке «Импорт».

## Локальный запуск

```bash
npm run serve        # http://localhost:8080
npm install && npm run sync   # синхронизация (секреты через переменные окружения)
```

Сайт использует ES-модули, поэтому его нужно открывать через HTTP-сервер, а не через `file://`.

## Структура

```
index.html              разметка
css/style.css           оформление
js/app.js               логика интерфейса
js/wheel.js             колесо (canvas)
js/effects.js           звук и конфетти
js/storage.js           localStorage + IndexedDB (гифки)
js/parsers.js           форматы импорта (общие с Node-скриптом)
js/collector.js         букмарклет-сборщик
scripts/fetch-games.mjs синхронизация Steam / PSN / Xbox / файлов
data/games.json         результат синхронизации
```
